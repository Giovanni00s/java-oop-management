# Java OOP Course & Student Management System

Progetto Java sviluppato per l'esame di Programmazione Orientata agli Oggetti (OOP) presso l'Università degli Studi di Salerno.

## Caratteristiche principali
- **Paradigmi OOP:** Utilizzo di incapsulamento, ereditarietà, polimorfismo e interfacce (`CourseRepository`).
- **Gestione Eccezioni:** Implementazione di eccezioni personalizzate (`StudentNotFoundException`).
- **Functional Programming:** Utilizzo di Stream e Espressioni Lambda per il filtraggio dei dati.
- **Strumenti:** Sviluppato tramite IntelliJ IDEA e controllato con Git.
